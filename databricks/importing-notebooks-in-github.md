#### Move your notebook or create a new one in one of the GitHub Repo folders in Databricks.

#### This error might appear when you try to commit a change:

```sql
Note: This notebook may have outputs, but they are not included because the workspace administrator disabled committing outputs.
```

#### What you wanna do is go to Settings > Development > `Allow repos to export IPYNB output. Allow committing .ipynb notebook output`. Make sure to select `Allow`.

#### Refresh the folder then commit your changes.
